# 订单数前三品目：逐件与未来20件复核

[中文](index.html) · [한국어](index_ko.html)。离线打开，无需服务或联网。

仅显示订单数最多的前三品目：284023（58单）、284047（51单）、284059（36单）。排名按dataset/orders.csv的唯一订单/明细计数，不按预测窗口数。

当前显示145个订单、644,051条原始称重；577,607个时刻有截至该点的80件输入预测。模型、训练CSV及既有训练测试预测均未覆盖。

点击任一填充点，以该点为决策时刻T，过去80件截至该点，展示未来20件均值、第10/20件重量和标准差的预测/实际对照。主图旧预测仍按被预测产品对齐；点击详情取所点击T的直接模型输出。即使点击主图h10预测线，详情也将点击的填充记录视为新的T，不误用早10件作出的预测。

分布展示预测q05～q95、90%单件范围、实际已观测未来20件直方图和经验CDF。七分位数不是20件有序预测，也不是均值置信区间；CDF只连接已知分位数，不外推两端尾部。原始异常点仍显示。未来实际不足20件、无效或跨断档时会标注，完整批次均值/分位数与有效误差不补造，已经作出的预测仍可显示。

四个设备参数仍显示每单完整开始至结束的所有原始记录，含零值和同秒事件；起点取更早状态，终点延续不是新增事件。训练和验证订单为拟合内回看，历史测试也并非新的独立盲测。新覆盖范围的指标不替代原发布样本评估。

原保存测试窗口中，本页涉及96,532条；四版本全部12个输出与保存预测逐一核验，见manifest.json的savedTestParity。

生成新目录：python -B -X utf8 model_预测平均重量/plot_filling_review.py --output NEW_DIR。更新现有页：python -B -X utf8 model_预测平均重量/plot_filling_review.py --enhance。已有相同模型和数据的详情缓存可复用。

核验：python -B -X utf8 tests/verify_filling_data.py；node tests/check_filling_frontend.cjs。Node DOM/Plotly测试不是浏览器/WebGL视觉验收。
