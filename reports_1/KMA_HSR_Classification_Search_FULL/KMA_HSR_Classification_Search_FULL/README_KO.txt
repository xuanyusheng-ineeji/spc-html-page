KMA HSR 강수 유형 분류 및 유사 사례 검색 (전체판 FULL)
======================================================

사용 방법
1. ZIP 파일을 원하는 폴더에 압축 해제합니다(바탕 화면 등). ZIP 안에서 바로 열지 말고 반드시 먼저 압축을 푸십시오.
2. 압축을 푼 폴더 안의 index.html 을 더블클릭합니다(Microsoft Edge 또는 Google Chrome 권장).
3. 인터넷 연결, Python, 서버 설치가 필요 없습니다.

포함 내용
- 후보 12,631 프레임 전체 검색·영상·Top-5
- 프레임마다 DINOv3+LR / M0 분류 결과와 P(TY), 사후 선별 상태, 주요 기상 지표
- 프레임마다 GOLDEN 유사 사례 Top-5(실제 과거 레이더 영상, 전문가 라벨, 시각, 기상 과정, 유사도)와 두 영상 비교
- 분류 통계(전체 12,631 프레임 기준)

유의 사항
- 이 12,631 프레임에는 GOLDEN 정답 라벨이 없습니다. 모델 출력은 검증된 정답이 아니며 P(TY)는 정확도가 아닙니다.
- GOLDEN 사례의 전문가 라벨은 현재 프레임의 정답이 아니며, 검색 결과는 모델 예측이 맞다는 독립적 증거가 아닙니다.
- 검색은 사후(retrospective) 방식입니다. 현재 프레임보다 늦은 GOLDEN 사례는 ‘사후 참조’로 표시됩니다.
- 모든 값은 기존 분석 결과를 그대로 읽은 것이며, 이 도구는 모델을 다시 실행하지 않습니다.

폴더 구성: index.html / app / data / img(q = 현재 프레임, g = GOLDEN 사례) / MANIFEST.csv(파일 목록과 sha256)
